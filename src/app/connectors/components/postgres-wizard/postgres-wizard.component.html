WHAT DOES THIS MEAN?
1

Connection Details

Tell us how to reach your PostgreSQL server. These are the same credentials you'd use in psql or a tool like DBeaver.

  • Connection Name — a friendly label shown in your workspace (e.g. "Postgres Production").
  • Host — the server address, such as a domain or IP (db.example.com).
  • Port — the network port Postgres listens on. Default is 5432.
  • Database Name — which database on the server to connect to.
  • Username / Password — the role credentials. Use a read-only user when possible.
2

Metadata Configuration

Controls how deeply we profile your tables when building the schema catalog. More records = more accurate stats, but slower fetch.

  • 1,000 (Default) — fast, good for most databases.
  • 10,000+ — better statistics on high-cardinality columns.
  • No limit — scans every row. Use only on small datasets.
